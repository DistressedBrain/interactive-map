Works like windows on your desktop: drag a card to move it (the grid shows where it will land) · pull the right/bottom edge or the corner to resize · click a card for precise sliders. "Save layout" stores it in this browser — the homepage uses it automatically. "Copy as config" copies the cs/rs/r values so you can paste them into js/widgets.js to make it permanent.
